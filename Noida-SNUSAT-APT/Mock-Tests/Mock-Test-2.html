A math test had only two-mark, five-mark and ten-mark questions. Each of these types had the same number of questions.

¼ of all the five-mark questions and ⅓ of all the ten-mark questions were from algebra. There were no two-mark questions from algebra.

What fraction of the total number of questions in the test were from algebra?

Source: 2027 paper, SNUSAT Q7

How to see it

A fraction of a fraction does not need the actual number; let it be n and it cancels.

Working

  1. Each type has n questions, so the test has 3n.
  2. Algebra = n/4 + n/3 = 7n/12.
  3. Fraction = (7n/12) / 3n = 7/36.
Answer — A — 7/36.
Common slip. Answering 7/12 — that is algebra as a fraction of one type's count, forgetting there are three types.

A pattern made using identical square tiles is given below. What is the number of tiles required to make the 21st figure in the pattern?

Source: 2025 paper, SNUSAT Q15

How to see it

Count small cases exactly and look for a sum of two squares — diamond lattices almost always give one.

Working

  1. Figure 1: 1 tile. Figure 2: a 2 × 2 diamond block with one tile in the middle = 5. Figure 3: 3² + 2² = 13.
  2. So figure n has n² + (n − 1)² tiles: the upright lattice plus the offset one nested inside it.
  3. Figure 21: 21² + 20² = 441 + 400 = 841.
  4. Note that 841 = 29², which is a coincidence, not the rule.
Answer — C — 841 tiles.
Common slip. Answering 441 = 21², which counts only one of the two interleaved lattices. It is option A precisely because it is the natural first guess.

Look at the flowchart below. Which of these could be the possible values of input ‘X’ and the output ‘X’?

Source: 2026 paper, SNUSAT Q16

How to see it

Run it once with a symbol rather than a number: the loop adds Z, then decreases Z, so the total added is a sum you can write down.

Working

  1. Start: X = x, Z = 4. The loop body is X ← X + Z, then test Z = 0?, and if not, Z ← Z − 1 and back to the body.
  2. Pass 1: X = x + 4, Z becomes 3. Pass 2: X = x + 7, Z becomes 2. Pass 3: X = x + 9, Z becomes 1. Pass 4: X = x + 10, Z becomes 0.

What fraction of the test's total marks comes from geometry?

Let each type have n questions. The n cancels, so the fraction is fixed — but be clear whether you are counting questions or marks.

Working

  1. Total marks = n(1 + 3 + 4) = 8n.

The image below shows the side, back and top views of a 3D block structure. Based on the given views, what is the maximum possible number of blocks that can be used to build this structure?

Source: 2026 paper, SNUSAT Q18

How to see it

The top view gives the footprint; the side view caps the height of each column of that footprint. For a maximum, push every column up to its cap.

Working

  1. Top view is 6 × 3, so the footprint is 6 long and 3 deep and every cell is occupied.
  2. Side view is the structure seen along the depth, 6 wide: its column heights read 3, 3, 3, 2, 1, 1, summing to 13.
  3. Back view is 3 × 3 fully filled, so somewhere along each of the 3 depth rows the height reaches 3 — satisfied by the first three columns.
  4. Maximum = make every one of the 3 depth rows match the side view: 3 × 13 = 39.
Answer — A — 39 blocks.
Common slip. Multiplying the bounding box, 6 × 3 × 3 = 54. That ignores the staircase in the side view, and 54 is offered as option D for exactly that reason.

The sum of the consecutive integers from (−30) to 200 is u.

What is the sum of the consecutive integers from (−200) to 32?

Source: 2027 paper, SNUSAT Q8

How to see it

−30 to 30 sums to zero, so u is really 31 + … + 200. Do the same trick on the second run.

Working

  1. u = (−30 + … + 30) + (31 + … + 200) = 31 + … + 200.
  2. −200 to 32: −32 to 32 cancels, leaving −(33 + … + 200).
  3. 33 + … + 200 = u − 31 − 32 = u − 63.
  4. So the sum is −(u − 63) = −u + 63.
Answer — A — (−u) + 63.
Common slip. Getting the sign of 63 wrong (C). The second run is mostly negative, so its sum must be near −u.

Two identical rectangular cards each have a length three times their breadth. The first card is cut lengthwise into three equal strips, and the second is cut breadthwise into three equal pieces.

If the perimeter of each strip from the first card is 40 cm, what is the perimeter of each piece from the second?

Source: Predicted 2027, SNUSAT V15

How to see it

Let the breadth be b. A lengthwise cut keeps the length; a breadthwise cut keeps the breadth. Write each piece's sides in b.

Working

  1. Card: 3b × b.
  2. Lengthwise into three: strips 3b × b/3, perimeter 2(3b + b/3) = 20b/3 = 40, so b = 6 cm.
  3. Breadthwise into three: pieces b × b = 6 × 6 squares.
  4. Perimeter = 4 × 6 = 24 cm.
Answer — C — 24 cm.
Common slip. Assuming the two kinds of piece have the same perimeter because they have the same area.

Anirudh's study table has a pile of 7 textbooks of Mathematics, English and Economics, arranged as shown. The rules are:

  1. The Economics books are placed only at the prime number positions in the pile.
  2. There are 4 Mathematics books, placed together.
  3. The book at the top is not a Mathematics book.
  4. The fewest number of books are English.

Which of the following is DEFINITELY true?

Source: 2025 paper, SNUSAT Q17

How to see it

Fix the counts first, then slide the block of four Maths books through the pile and keep only the positions that work.

Working

  1. 7 books = 4 Maths + Economics + English, so Economics + English = 3. English is fewest, so English = 1 and Economics = 2.
  2. Prime positions in 1–7 are 2, 3, 5, 7. The two Economics books must sit among those.
  3. The Maths block of four cannot start at 1 (rule 3), so it is 2–5, 3–6 or 4–7.
  4. 2–5 leaves 1, 6, 7 — only 7 is prime, so there is nowhere for the second Economics book. Rejected.
  5. 3–6 leaves 1, 2, 7: Economics at 2 and 7, English at 1. Works.
  6. 4–7 leaves 1, 2, 3: Economics at 2 and 3, English at 1. Works.
  7. Both survivors put English at position 1; nothing else is common to them.
Answer — A — an English book is at position 1.
Common slip. Stopping at the first arrangement that works and reading the answer off it. With two arrangements alive, only what they agree on is “definitely true”.

Chain the multipliers. Two of them are designed to cancel exactly.

Working

  1. Multipliers: 1·02, 0·98, 1·25, 0·80.
  2. 1·02 × 0·98 = 0·9996 — not quite 1, but within 0·04%.

What is the ratio of the four pieces by weight?

You cannot mix a ratio within a part into the ratio of the whole. Rescale so the split part divides exactly.

Which of the following could be the breadth and height of the shelf respectively, such that the boxes exactly fit in?

Source: 2026 paper, SNUSAT Q15

How to see it

Height comes from one box; breadth comes from the total floor the 60 boxes need.

Working

  1. One box: height = volume ÷ floor area = 7·5 ÷ 2·5 = 3 m. No stacking, so the shelf is 3 m high.
  2. Total floor needed = 60 × 2·5 = 150 m².
  3. Shelf floor = length × breadth = 12 × b = 150 ⇒ b = 12·5 m.
  4. So breadth 12·5 m and height 3 m.
Answer — B — 12·5 m and 3 m.

Shown below are four designs. Design P is embedded in either one or more of the other designs. Which of the other designs have P (or a rotated form of P) embedded in them?

Source: 2025 paper, SNUSAT Q19

How to see it

Pick the rarest feature of P and hunt for that, instead of comparing whole pictures.

Working

  1. P is a square carrying three interior lines: a short vertical from the top edge down to a point inside, a line from the left edge meeting that point, and a line from the top of the vertical sloping to the right edge — plus a long line down to the bottom-right corner.
  2. The rare feature is that junction: a vertical stub meeting two slants at one interior point, with a long line running to a corner.
  3. Rotate P by 90°, 180° and 270° and look for that junction in each grid. It is present in Q and in S; R has no vertical stub meeting a slant at an interior point in the required way.
  4. The lines of P must all be present and the angles preserved — a rotation is allowed, a reflection or a rescale is not.
Answer — C — only Q and S.
Common slip. Matching on “busyness”. R is the densest grid and therefore feels most likely to contain anything, which is why it is the distractor.

Two statements about two types of water bodies — lakes and oceans — are followed by three conclusions.

Statement I: All oceans are salty.
Statement II: Lakes and oceans are different water bodies.

Conclusion (i): No lakes are salty.
Conclusion (ii): Lakes may or may not be salty.
Conclusion (iii): No water body can be classified as both a lake and an ocean.

Which of the following conclusions logically follow from Statements I and II?

Source: 2025 paper, SNUSAT Q5

How to see it

“All oceans are salty” says nothing at all about non-oceans.

Working

  1. (i) is the classic inversion error: all oceans are salty does not make saltiness exclusive to oceans. False.
  2. (ii) is exactly the right amount of ignorance — the premises leave lakes open either way. Follows.
  3. (iii) is a restatement of Statement II: being different kinds of water body means nothing is both. Follows.
Answer — D — (ii) and (iii) only.
Common slip. Rejecting (ii) because it “says nothing”. In syllogism questions a conclusion that records uncertainty is often the only valid one.

Read the following statement.

“If you go outside without a coat, you will catch a cold and infect the rest of the family. Then your sister will have to miss her classes and she will get a bad grade and eventually, fail her course.”

Which of the following fallacies BEST describes the statement above?

Source: 2025 paper, SNUSAT Q4

How to see it

Count the links. A fallacy with a chain of then … then … is almost always the slippery slope.

Working

  1. Lay the statement out as a chain: no coat → catches cold → infects the family → sister misses class → bad grade → fails the course.
  2. That is five links, each asserted as if it were certain, ending somewhere far more serious than where it began. Both features are the signature of the slippery slope.
  3. Check the others do not fit: there is no forced choice between two options (A), no leap from a small sample to a universal rule (B), and nobody's character is attacked (D).
  4. Note that each individual link is merely unlikely; the fallacy is in treating the whole chain as inevitable.
Answer — C — slippery slope.
Common slip. Reading “you will catch a cold” as a hasty generalization. The defect is the chain, not the sample size.

A college library will stay open until midnight during the examination month. The librarian argues: “Many students have told us they cannot study at home in the evening. Longer hours will therefore improve examination results.”

Which of the following is a critical assumption of the librarian's argument?

Source: Predicted 2027, SNUSAT V6

How to see it

Negate each candidate. If the argument collapses when it is false, it is the assumption; if the argument survives, it was not needed.

Working

  1. Negate D: those students would not use the extra hours to study. Then the longer hours cannot raise their results, and the argument falls. So D is assumed.
  2. Negate A: some home-studiers do as well as library users. The argument survives — it is only about students who cannot study at home.
  3. Negate B: the hours are expensive. Cost has nothing to do with whether results improve.
  4. Negate C: not every student comes. Results can still improve for those who do. C is far stronger than the argument needs.
Answer — D — the students who need the space will use it to study.
Common slip. Picking the extreme option (C or A). An assumption is the minimum the argument needs, so words like “every” and “always” usually mark a distractor.

  4. (iii) XY′ + YX′ = XY + YX. Transpose: (XY)′ + (YX)′ = YX + XY, the same sum. Symmetric.
  5. So (i) and (iii).
Answer — B — only (i) and (iii).
Common slip. Assuming the product of two symmetric matrices is symmetric. It is symmetric iff they commute — and (ii) is in the paper to catch exactly that.
